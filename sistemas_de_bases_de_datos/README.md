# Análisis de negocio

# Descripción
Este repositorio contiene consultas SQL implementadas en notebooks Jupyter para analizar datos empresariales. Las consultas están diseñadas para extraer información valiosa sobre ventas, proveedores, clientes y comportamiento transaccional.

# Estructura 

Análisis_de_ventas.ipynb
Este notebook contiene consultas SQL que:

- Muestran todos los registros de las tablas relacionadas con ventas
- Calculan el promedio de montos por cliente
- Cuentan el número de boletas por cliente y categoría
- Determinan el total de productos comprados por cada cliente
- Proporcionan una visión general del comportamiento de compra de los clientes

Análisis_de_negocio.ipynb
Este notebook incluye consultas SQL enfocadas en:

- Encontrar productos que no son suministrados por un proveedor específico
- Identificar al cliente que ha gastado más dinero
- Encontrar al proveedor con mayor volumen de ventas
- Obtener los meses con ventas por debajo del promedio
- Analizar la relación entre proveedores, productos y rendimiento

Análisis_transaccional.ipynb
Este notebook se enfoca en el análisis de transacciones mediante consultas que:

- Calculan el total gastado por cada cliente en productos
- Encuentran clientes que no han realizado compras
- Identifican al cliente con el mayor gasto total
- Analizan patrones de gasto y comportamiento transaccional

# Tecnologías Utilizadas

- SQL para consultas y análisis de datos
- Jupyter Notebook como entorno interactivo
- Python para la integración con bases de datos
